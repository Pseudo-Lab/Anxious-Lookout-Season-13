## 초조한 전망대 소개

빠르게 흘러가는 뉴스를 일회성으로 소비하지 않고, 각자가 선택한 주제를 4개월 동안 꾸준히 **관찰하고, 기록하고, 해석하는** 프로젝트입니다. 이 과정에서 자료 조사와 글쓰기를 돕는 에이전트도 직접 만들고 실험합니다.

참가자는 단순한 기사 모음을 넘어 시간의 흐름과 주요 사건, 관점의 변화, 남은 질문을 하나의 긴 글로 완성합니다. 각자의 글을 모아 초조한 전망대의 책으로 펴냅니다.

## 우리가 던지는 질문

- 한 주제를 4개월 동안 꾸준히 따라가면 처음의 생각은 어떻게 달라질까?
- 흩어져 보이던 사건을 시간순으로 놓으면 어떤 흐름과 전환점이 보일까?
- 뉴스를 요약하는 데서 그치지 않고, 자신의 질문과 관점이 담긴 글로 발전시키려면 무엇이 필요할까?
- 에이전트는 자료 수집과 정리를 어디까지 맡을 수 있고, 사람은 어떤 판단을 끝까지 책임져야 할까?

## 목표

### 1. 4개월의 기록을 책으로 펴내기

참가자마다 하나의 주제를 정해 4개월 동안 관련 뉴스를 따라갑니다. 마지막에는 쌓인 기록을 하나의 이야기와 주장으로 엮고, 각자의 글을 모아 한 권의 책으로 펴냅니다.

### 2. 관심 주제를 자기 관점이 담긴 글로 발전시키기

- 시작할 때 주제와 핵심 질문을 명확히 정합니다.
- 매주 핵심 뉴스를 읽고 선택 이유와 생각을 기록합니다.
- 사건 사이의 연결과 이해관계자의 입장, 반복해서 등장하는 주장과 반론을 추적합니다.
- 중간 점검에서 처음의 가설과 관점이 어떻게 바뀌었는지 살펴봅니다.
- 4개월의 기록을 하나의 이야기와 주장으로 완성합니다.

### 3. 자료 조사와 글쓰기를 돕는 에이전트 만들기

OCI 환경에 참가자들이 함께 쓸 수 있는 에이전트를 만들고 실제 활동에 사용합니다. 에이전트는 사람을 대신해 결론을 내리는 도구가 아니라, 놓치기 쉬운 자료를 찾고 기록을 체계적으로 정리하며 빠진 관점과 논리의 빈틈을 짚어주는 동료로 설계합니다.

## 주제 선정 기준

주제는 넓은 분야명보다 **4개월 동안 변화와 논쟁을 따라가며 답을 찾아갈 수 있는 구체적인 질문**으로 정합니다.

| 넓은 주제 | 4개월 동안 답을 찾아갈 질문 |
| --- | --- |
| AI | 생성형 AI 도입이 주니어 개발자의 역할을 어떻게 바꾸는가? |
| 전기차 | 전기차 캐즘 논쟁 속에서 배터리 산업의 투자 방향은 어떻게 변하는가? |
| 지역 소멸 | 지역 소멸 대응 정책에서 청년 정착보다 관광이 앞서는 이유는 무엇인가? |

주제 선언문에는 다음 내용을 담습니다.

1. 4개월 동안 따라갈 주제
2. 지금 이 주제가 중요하다고 생각하는 이유
3. 시작할 때 품고 있던 가설이나 선입견
4. 계속 확인하고 싶은 핵심 질문 2~3개
5. 우선적으로 볼 매체·기관·전문가·당사자
6. 어디까지 다룰지와 무엇을 제외할지

## 4개월 활동 계획

| 단계 | 초점 | 주요 활동 | 결과물 |
| --- | --- | --- | --- |
| 준비 주간 | 질문과 범위 정하기 | 주제 선언, 키워드·출처·알림 조건 설정, 사실 확인 원칙 공유 | 주제 선언문, 초기 가설, 주요 출처 목록 |
| 1개월 차 | 넓게 읽고 전체 흐름 파악하기 | 핵심 뉴스 선정, 주요 이해관계자와 반복해서 등장하는 쟁점 파악 | 뉴스 카드 4개, 주제 관계도, 첫 달 정리 글 |
| 2개월 차 | 연결하고 비교하기 | 시간순으로 사건 정리, 매체별 보도 관점과 이해관계자의 입장 비교 | 사건 흐름표, 관점 비교표, 중간 발표, 둘째 달 정리 글 |
| 3개월 차 | 관점과 논지 세우기 | 전환점 선정, 글에서 다룰 핵심 주장과 목차 초안 작성, 근거·반론 연결 | 개인 원고 목차, 핵심 주장, 근거 목록, 원고 초안 |
| 4개월 차 | 쓰고 확인하고 엮기 | 초안 쓰기, 서로 초안을 읽고 의견 주고받기, 사실·인용·링크 확인 | 최종 원고, 참고문헌, 함께 쓰는 서문·후기, 출간용 원고 |

## 주간 기본 루틴

1. **이번 주 기사 후보 살펴보기** — 에이전트가 모은 기사와 주요 변화를 살펴봅니다.
2. **핵심 뉴스 고르기** — 반드시 읽을 기사 1~3건을 직접 고릅니다.
3. **뉴스 카드 작성** — 사실, 맥락, 생각, 남은 질문을 기록합니다.
4. **함께 이야기하기** — 온라인에서 3~5분 동안 이번 주에 눈여겨본 변화를 소개합니다.
5. **서로 질문하기** — 다른 참가자가 반론이나 연결점, 추가로 볼 자료를 제안합니다.
6. **기록 모으기** — 기사와 메모, 질문, 인용을 함께 쓰는 저장 공간에 모읍니다.

### 뉴스 카드 템플릿

- 기사 제목 / 출처 / 날짜 / 링크
- 사실을 세 문장으로 요약
- 이 뉴스가 내 주제에서 중요한 이유
- 이전 뉴스와 연결되는 지점
- 이해관계자마다 입장이 어떻게 다른지
- 내가 동의하지 않거나 의심하는 부분
- 다음 주에 확인할 질문
- 최종 원고에 사용할 가능성: 높음 / 보통 / 낮음

## 활동 방식

- **매주 각자 기록하기:** 뉴스 카드를 작성합니다.
- **격주 온라인 모임:** 지난 2주간의 주요 변화를 나누고 서로 질문하며 토론합니다.
- **한 달 정리:** 한 달 동안 살펴본 흐름을 긴 글로 정리합니다.
- **중간 점검:** 2개월 차에 주제와 관점, 논지를 함께 살펴봅니다.
- **오프라인 글쓰기 모임:** 목차와 초안을 함께 다듬습니다.
- **최종 원고 함께 검토하기:** 출간 전에 사실을 확인하고 편집 방향을 맞춥니다.

발표를 길게 준비하기보다 미리 작성한 뉴스 카드와 질문을 중심으로 대화합니다. 진행자는 내용을 평가하기보다 생각을 더 깊게 만드는 질문과 서로 이어지는 지점을 찾습니다.

## 최종 결과물

함께 만드는 책은 다음 흐름으로 구성합니다.

1. 왜 우리는 뉴스를 4개월 동안 따라갔는가
2. 우리가 읽고 쓰며 에이전트를 활용한 방식
3. 참가자별 글
4. 서로 다른 주제가 만나는 지점
5. 자료 조사에서 에이전트가 해낸 일과 한계
6. 4개월 후에도 남은 질문

참가자별 원고 분량은 **약 8천~1만 5천 자**를 기준으로 하며, 참가자 수와 출간 방식에 따라 조정합니다.

원한다면 완성된 원고 중 일부를 오디오 에세이, 카드뉴스, 짧은 영상 등 다른 형식으로도 만들어 봅니다. 이때도 사실 확인과 편집을 마친 원고와 출처 목록을 바탕으로 만들고, 마지막에는 사람이 직접 확인합니다.

## OCI 에이전트 MVP

하나의 메인 에이전트가 작업 목표를 파악하고 필요한 스킬(Skill)과 도구(Tool)를 선택하는 구조로 시작합니다. 서브 에이전트(Subagent)는 여러 조사를 동시에 진행하거나 별도로 검증해야 할 때만 사용합니다.

### 처음 구현할 스킬

- **뉴스 조사:** 관련 기사를 모으고 중요한 기사를 추려내기
- **분석·검증:** 시간의 흐름과 반론, 빠진 관점을 살피고 사실 확인하기
- **글쓰기·다듬기:** 뉴스 카드와 목차, 원고 초안 만들기
- **운영·기록 관리:** 확인을 마친 기록 저장과 활동 관리

### 처음 연동할 도구

- 키워드·RSS·지정 매체 기반 뉴스 후보 수집
- 기사 원문과 기본 정보 불러오기
- 겹치거나 비슷한 기사 찾기
- 기사, 뉴스 카드, 인용과 질문 저장·불러오기
- 주제별 사건 흐름과 과거 기록 검색
- 숫자·날짜·인용·링크 확인 돕기
- 주간 요약에 필요한 자료 불러오기와 정기 작업 실행

MVP는 **메인 에이전트 + 뉴스 조사 스킬 + 검색·RSS 수집·저장 도구 + 주간 브리핑을 정해진 시간에 실행하는 기능**부터 구현합니다.

## 사람과 에이전트의 역할

| 에이전트에게 맡기는 일 | 사람이 끝까지 맡는 일 |
| --- | --- |
| 자료를 폭넓게 찾고 반복 작업 줄이기 | 중요한 뉴스 선택하기 |
| 자료를 같은 형식으로 정리하기 | 출처의 신뢰성 판단하기 |
| 이전 기록과 이어지는 지점 찾기 | 사실과 해석 구분하기 |
| 빠진 관점과 확인 질문 제안하기 | 주장과 문체 결정하기 |
| 다시 확인할 부분 표시하기 | 민감한 내용과 저작권 문제를 살피고 최종 원고에 책임지기 |

> 에이전트가 만든 요약은 출처가 아닙니다. 모든 핵심 주장과 인용은 원문으로 돌아가 확인합니다.

## 참여 역할

개발 경험이 없어도 참여할 수 있습니다. 아래 역할은 참가자들이 돌아가며 맡습니다.

- **관찰자:** 새로운 사건과 자료를 찾습니다.
- **질문자:** 당연하게 여긴 전제에 질문합니다.
- **연결자:** 다른 주제와 과거 사건, 참가자의 기록을 연결합니다.
- **팩트체커:** 숫자와 날짜, 인용을 원문과 대조합니다.
- **편집자:** 글의 흐름과 독자가 이해하기 어려운 부분을 살핍니다.
- **메이커:** OCI 에이전트와 자동화 기능을 만듭니다.

모든 참가자가 개발할 필요는 없습니다. 좋은 출처와 분류 기준, 질문, 실패 사례, 편집 의견도 에이전트를 만드는 데 중요한 기여가 됩니다.

## 완주 기준

### 개인

- [ ] 주제 선언문 1개
- [ ] 전체 활동 주차의 75% 이상 뉴스 카드 작성
- [ ] 한 달 정리 글 4개
- [ ] 중간 발표를 하고 다른 참가자의 의견 받기 1회 이상
- [ ] 최종 원고와 출처 목록 제출
- [ ] 에이전트가 만든 결과물을 직접 확인하고 고친 사례 기록

### 공동

- [ ] 공통 편집 원칙과 출처 표기 방식 확정
- [ ] OCI 에이전트 MVP를 실제 주간 활동에 사용
- [ ] 참가자별 원고를 함께 읽고 사실 확인 마치기
- [ ] 공동 서문·후기·목차 완성
- [ ] 전자책이나 소량 인쇄본으로 출간
- [ ] 에이전트를 만들고 운영하며 배운 점 공개

- 전체 일정과 출간 목표일

- 주간 기록의 최소 기준
- 격주 모임 시간과 진행 방식
- 공통 출처·인용 표기 규칙
- OCI 에이전트 MVP의 범위와 담당자
- 원고 편집자와 기술 운영자의 역할

## 우리가 남기려는 것

결과물은 책 한 권만이 아닙니다.

- 한 주제를 오래 관찰하는 습관
- 뉴스에서 사실과 해석을 구분하는 방법
- 흩어진 기록을 자기 관점이 담긴 글로 엮는 경험
- 에이전트를 맹신하지 않고 동료로 활용하며 결과를 확인하는 기준
- 다음 시즌에도 다시 쓸 수 있는 자료 조사와 글쓰기 기반

**초조함은 뉴스를 더 많이 보는 것으로 사라지지 않습니다. 한 걸음 물러나 오래 바라보고, 기록하고, 연결하고, 자기 언어로 써볼 때 전망이 생깁니다.**
